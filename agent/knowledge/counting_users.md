# Counting users

`brand_firstpartyid` is the default unit for counting users anywhere under
Acme.

`crm_customer_ref` maps 1:1 to that unit and is the identifier for segment work.

## Northwind-only identifier ladder

The Northwind identifier ladder is a special case. It applies only under a
Northwind-scoped question. Naming that ladder without this heading is how it
gets read as company-wide. Do not use it as the Acme default.
